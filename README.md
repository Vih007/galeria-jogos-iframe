# Galeria de Jogos Dinâmica 🎮

Este projeto é uma aplicação web simples e elegante que exibe diferentes jogos em uma galeria interativa. Ele utiliza **iframes** para carregar conteúdos de páginas externas de forma dinâmica, permitindo a navegação manual ou automática.

## 🚀 Funcionalidades
* **Navegação Inteligente:** Botões de "Próximo" e "Anterior" para navegar entre as páginas dos jogos.
* **Slideshow Automático:** O sistema alterna automaticamente entre os jogos a cada 3 segundos.
* **Interface Temática:** Design focado em gaming, com fundo personalizado e elementos semitransparentes.
* **Organização Modular:** Uso de CSS externo e páginas HTML separadas para cada jogo.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação das páginas e tabelas de layout.
* **CSS3:** Estilização visual, efeitos de hover e posicionamento.
* **JavaScript (Vanilla):** Lógica de controle do iframe, manipulação de array de páginas e temporizador (`setInterval`).

## 📂 Estrutura do Projeto
- `index.html`: Página principal com o container do iframe e controles.
- `style.css`: Folha de estilo global para os iframes.
- `pag1.html` a `pag6.html`: Páginas de conteúdo individual para cada jogo.
- `/imagens`: Pasta contendo os recursos visuais do projeto.
